# Meow Page 🐱

An interactive digital postcard site — create, customize, preview, and share a little meow with someone.

## Status
Phase 1 — Skeleton (home page, create page, basic layout, no interactivity yet)

## Structure
```
meow-page/
├── index.html
├── create.html
├── css/
│   ├── style.css       # base layout & structure
│   ├── animations.css  # (Phase 4)
│   └── responsive.css  # (Phase 6)
├── js/
│   ├── main.js
│   ├── postcard.js      # (Phase 2)
│   └── share.js         # (Phase 5)
└── assets/
    ├── cats/
    ├── backgrounds/
    ├── stickers/
    └── sounds/
```

## Run it
Just open `index.html` in a browser. No build step, no server needed.
